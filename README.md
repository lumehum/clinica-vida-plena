# mimihum

A small personal website for travel, activities, and everyday stories.

## Pages

- `index.html`: personal homepage
- `chile-2026/index.html`: public Chile travel landing with a link to the access-controlled private guide
- `activities/index.html`: public activities placeholder
- `styles.css`: shared responsive styles

The site is plain HTML and CSS with inline decorative SVG illustrations. No build step, JavaScript, forms, analytics, or third-party assets are required. GitHub Pages publishes the site from the existing main-branch configuration.

All navigation and asset paths are relative so the site can move with a future account or repository rename. The public pages intentionally contain no itinerary dates, reservations, contact information, or private documents. The Chile landing links to a separately hosted private guide that requires an authorized ChatGPT account; the guide content is not stored in this repository.

## Editing and checks

Update the corresponding HTML file and retain its page title, description, heading structure, and navigation. Preview both narrow and wide layouts, confirm keyboard focus is visible, and check the home, travel, and activity links. Commit changes normally to preserve history; earlier versions remain available in Git history.
